# Muse 用量小组件

Scripting（iOS）小组件，显示 Muse 每周免费额度用了百分之几、什么时候重置、额外 token 还剩多少。

## 文件

- `index.tsx` — App 入口（在 App 里打开时显示）
- `widget.tsx` — 主屏幕小组件
- `app_intents.tsx` — “刷新”按钮的 Intent（点一下立刻重新抓数据）

## 数据来源

小组件从这个 Worker 抓数据（不是直接读 Muse）：

https://muse.562156080.workers.dev/

Worker 里的数据由服务器上的定时任务每 10 分钟推一次新值。小组件自己每 10 分钟左右自动刷新（向 iOS 请求的间隔，实际可能慢一点）；点“刷新”按钮是立刻手动刷一次。

## 在 Scripting 里用（远程资源拉取）

1. 在 Scripting 里新建一个项目（空壳就行）。
2. 打开项目设置 → 远程资源，粘贴这个仓库的链接。
3. 打开自动更新，点“立即更新”，代码就拉下来了。
4. 以后仓库一更新，手机这边自动跟着更新，不用再手动导文件。

## 注意

- 后端更新脚本（`update-usage.py` / `worker.js`）不在这个仓库里，在服务器上跑。
- 小组件里没有任何 token、密钥，只抓上面那个公开的 Worker 地址。
